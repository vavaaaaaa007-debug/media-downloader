媒体下载器 —— 安装说明
========================================

批量下载 Google Drive 和 Facebook Reels 的图片、视频，并按序号自动命名。
不需要安装 Python 或其他任何软件，解压后双击就能用。


一、先确认自己的电脑，拿对版本
----------------------------------------
  Windows 64 位（Windows 10 或更新）     → media-downloader-windows-x64
  Mac，Apple 芯片（M1 / M2 / M3 / M4 …）  → media-downloader-macos-arm64
  Mac，Intel 芯片                          → media-downloader-macos-x64

  Mac 需要 macOS 11 或更新。
  不知道 Mac 是哪种芯片：点屏幕左上角苹果菜单 → 关于本机，看“芯片”或“处理器”那一行。
    写着 Apple M… 的选 arm64；写着 Intel 的选 x64。
  版本拿错会打不开，换对的版本就好。


二、Windows 安装
----------------------------------------
  1. 解压压缩包，得到「媒体下载器.exe」。
     可以放在任意文件夹，比如桌面或「文档」。不要直接在压缩包里双击运行。
  2. 双击「媒体下载器.exe」。
  3. 第一次打开可能出现蓝色窗口“Windows 已保护你的电脑”：
     点「更多信息」→「仍要运行」。之后不会再提示。
  4. 每次启动要等几秒，这是正常的。

  如果杀毒软件把它拦截或删除了：这是因为软件没有购买付费的代码签名证书，
  被误判的情况比较常见。确认文件来自可信的人后，可在杀毒软件里把它加入“信任/白名单”。


三、Mac 安装
----------------------------------------
  1. 双击压缩包解压，得到「媒体下载器」应用。
  2. 把它拖进「应用程序」文件夹（也可以放在别的文件夹）。
  3. 第一次打开时系统可能拦截，提示“无法验证开发者”或“无法打开”：
       方法一：右键（或按住 control 点）应用 → 选「打开」→ 再点「打开」。
       方法二：如果没有「打开」选项，先双击一次，然后到
               「系统设置」→「隐私与安全性」，往下找到媒体下载器，
               点「仍要打开」，输入电脑密码。
     只有第一次需要这样，之后可以正常双击打开。

  如果提示“已损坏，无法打开”：
     这通常不是文件真的坏了，而是 macOS 对没有付费签名的应用的拦截。
     确认软件来自可信的人后，打开「终端」，粘贴下面这一行后按回车
     （把路径换成应用实际所在的位置）：

       xattr -dr com.apple.quarantine /Applications/媒体下载器.app

     然后再按上面的方法一打开。


四、怎么用
----------------------------------------
  1. 复制链接，在软件里按 ⌘V（Windows 是 Ctrl+V）粘贴。可以多次粘贴，编号接着往下排。
  2. 支持这些写法，可以混在一起粘贴：
       • Google Drive 文件分享链接（图片、视频都行）
       • Google Drive 文件夹链接：文件夹里的图片和视频算一个系列，命名为 01-1、01-2 …
       • Facebook Reels 链接
       • 从 Google 表格 / Excel 复制的多行多列：同一行的链接算一个系列；
         「点击下载」这类超链接文字也能认出背后的链接
  3. 设置起始序号和序号位数，选择保存文件夹，点「开始下载」。
  4. 一批里同时有图片和视频时，下载结束后会自动分到「图片」「视频」两个文件夹。
  5. 同名文件不会被覆盖，会自动改名为 01(1).jpg 这样。


五、常见问题
----------------------------------------
  • 一直连接不上 / 超时：
      Google Drive 和 Facebook 在部分地区无法直接访问，需要先开启代理或 VPN。
  • 提示“没有访问权限”：
      分享设置要改为“知道链接的任何人可查看”，私密文件下载不了。
  • 提示“下载次数被谷歌限制”或“请求过于频繁”：
      过几个小时再点「继续下载」，已经下好的不会重复下载。
  • 出现问题想找人帮忙：
      点日志区的「复制日志」，把内容发给提供软件的人。
      日志里不含你的账号或密码。


六、卸载
----------------------------------------
  直接删除应用（Windows 删除 媒体下载器.exe）即可。
  软件只额外保存了一个很小的设置文件（记住上次的保存文件夹），想一起删掉的话在：
    Mac：     ~/Library/Application Support/媒体下载器/
    Windows： %APPDATA%\媒体下载器\
  已经下载的图片和视频不会被删除。
